# 10-subframe — Global Trekker OEM + Owner Outriggers

OEM subframe (ADR-0003) imported as STEP from vendor (when available).
Owner-side fabrication adds outriggers, side-toolbox brackets, step
mounts, and the lift-box hitch carrier.

## Files (planned)

- `gt-subframe-vendor.step` — vendor-supplied geometry.
- `outriggers-master.FCStd` — owner-side fabrications.
- `liftbox-carrier.FCStd` — hitch-class structural carrier for the
  enclosed bike lift box.
- Drawings, DXFs, and G-code for any owner-fabricated steel parts.
