# Build Log

Dated entries for design, fabrication, and shakedown phases. Photos
under `build-log/<YYYY-MM-DD>-<slug>/`.

## Phases (per REQUIREMENTS.md §22)

1. Design freeze
2. Chassis prep
3. Subframe fab + install
4. Shell delivery + mount + penetrations sealed
5. Rough-in (wiring, plumbing, HVAC, tanks)
6. Insulation augmentation
7. Cabinetry CNC + dry-fit
8. Wet systems commissioning
9. Electrical commissioning
10. Finish carpentry
11. Shakedown
12. Final weigh + registration
