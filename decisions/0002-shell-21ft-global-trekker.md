# ADR-0002: Habitat Shell — Global Trekker 21' with Tapered Tail

- **Status:** Accepted
- **Date:** 2026-05-07
- **Related:** REQUIREMENTS.md §3; ADR-0003 (subframe), ADR-0005 (bed)

## Context

Need a composite habitat shell that supports a fixed cabover bed, dry
bath, full galley, dinette, and the systems bay. Must allow rear
departure-angle taper and the cab pass-through.

## Options considered

1. **Global Trekker 19'.** Lighter, better departure angle, but tight
   for a fixed cabover + dry bath + dinette + lift-box clearance.
2. **Global Trekker 21' (chosen).** Fits a fixed cabover bed, dry bath,
   permanent dinette, large galley.
3. **Total Composites / Compositek custom box.** More flexibility,
   higher engineering load on the owner; rejected to keep schedule.

## Decision

21' Global Trekker habitat shell with rear-end departure-angle taper
producing ~23' total exterior length.

## Consequences

- Cabover nose extends over the F550 crew cab roof (ADR-0001);
  pass-through gasketed and insulated.
- Tail taper sheds frame ahead of the bike lift box (ADR-0006) so the
  box, when stowed, doesn't worsen departure angle.
- Heavier than the 19'; weight/CG model in §4 must include full +
  empty cases for 120 gal fresh, 40+40 gal grey/black.
