# Suppliers — Cross-Reference

Buy off-the-shelf wherever it makes sense. Custom fab is reserved for
the things that are genuinely custom (subframe brackets, lift-box,
cabinetry). Everything below is "things we should source, not build."

| Need | Vendor(s) |
|---|---|
| Liquid Springs CLASS suspension | Liquid Springs (direct) |
| 41" tires + 17/20" wheels | Toyo M55, Nitto Trail Grappler, BFG KM3; American Force / Method wheels |
| Aux fuel tank | Transfer Flow, Titan Fuel Tanks |
