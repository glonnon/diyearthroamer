# Vendor Docs

Drop datasheets, install manuals, and dimensional drawings here as
they're collected. Organized by subsystem.

## Suggested structure

```
vendor-docs/
  chassis/      Ford body builder's guide, Liquid Springs install
  shell/        Global Trekker shell drawings, subframe spec
  electrical/   Epoch datasheets, Victron manuals
  hvac/         Webasto / Aqua-Hot / Mabru / Velit
  plumbing/     Tanks, pumps, fixtures, UV
  windows/      Tern / Seitz dimensions and templates
  doors/        Composite plug door spec
```

Large PDFs are tracked via Git LFS (see `.gitattributes`).
